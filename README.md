แฟลชการ์ดชุดคำถามเกี่ยวกับการพัฒนาเกม ทำขึ้นเป็นโปรเจกต์สำหรับฝึกฝน Frontend

🔗 **ลองใช้งาน:** https://moost001.github.io/gamedev-flashcards/

 โปรเจกต์นี้คืออะไร

เว็บสำหรับทบทวนความรู้ด้านการพัฒนาเกมด้วยการ์ดคำถาม-เฉลย หน้าเว็บแสดงคำถามบนการ์ด เมื่อแตะการ์ดก็จะเห็นเฉลย แล้วให้ประเมินตัวเองว่าจำได้หรือยัง เหมาะกับการทบทวนซ้ำ ๆ จนกว่าจะเคลียร์เด็คครบ

หน้าเว็บเป็นภาษาไทย

ฟีเจอร์

- **สองโหมด** ทบทวน และ ทดสอบ
- **พลิกการ์ดดูเฉลย** แตะที่การ์ด หรือกดปุ่ม `Space`
- **ประเมินตัวเอง** หลังดูเฉลย เลือกได้ว่า `1` ยังไม่แม่น หรือ `2` จำได้แล้ว
- **ตัวนับความคืบหน้า** แสดงจำนวนการ์ดที่ผ่านแล้ว และรอบที่กำลังเล่น
- **เคลียร์เด็ค** เมื่อทำครบจะขึ้นหน้าจบรอบ และกด "เล่นใหม่อีกครั้ง" เพื่อเริ่มรอบใหม่ได้

วิธีใช้งาน

1. เปิดเว็บตามลิงก์ด้านบน
2. เลือกโหมด **ทบทวน** หรือ **ทดสอบ**
3. อ่านคำถามบนการ์ด แล้วแตะการ์ด (หรือกด `Space`) เพื่อดูเฉลย
4. กด `1` ถ้ายังไม่แม่น หรือ `2` ถ้าจำได้แล้ว
5. ทำต่อจนเคลียร์เด็ค แล้วเลือกเล่นใหม่ได้เมื่ออยากทบทวนอีกรอบ
